# s4sfitness.com

The S4S Fitness website. Hosted on Netlify, payments by Stripe.

- **Pages:** generated by `_build/build.py` (edit content there, then run `python3 _build/build.py`).
- **Styles / behaviour:** `styles.css`, `site.js`.
- **Checkout:** `netlify/functions/create-checkout.mjs` — price and delivery rates live here.
- **Sold-out sizes:** set a size to `false` in `stock.json`.
- **Netlify setting needed:** environment variable `STRIPE_SECRET_KEY`.
